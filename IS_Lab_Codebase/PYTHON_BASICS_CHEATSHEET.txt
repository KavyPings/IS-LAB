2. CHARACTER <-> NUMBER  (the core of every classical cipher)
--------------------------------------------------------------------------------
ord('A')                   -> 65          character to ASCII code
chr(65)                    -> 'A'         ASCII code to character

chr(n % 26 + 65)           -> letter      number back to letter, wrapped
ord(c) - ord('a')                         same thing for lowercase
[ord(c) for c in "ABC"]    -> [65,66,67]
"".join(chr(n) for n in [72,73])  -> "HI"
